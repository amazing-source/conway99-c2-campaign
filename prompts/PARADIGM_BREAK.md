# Paradigm-break research mode

Use when a long-running session has converged into a familiar program (for example lattice classification -> root systems -> case tables).

Do not continue a classification merely because it is already built.

Temporarily forget catalogue names and ask what is physically being assembled.

Representation-mutation examples:
- projection profiles rather than vectors;
- resource consumption rather than root counts;
- residual obligations rather than partial graphs;
- gluing operations rather than cases;
- minimal information distinguishing extendable from nonextendable partial objects.

Counterfactuals:
- if every local piece extends but the full object fails, what accumulates?
- if a full object exists, what construction rule explains the local flexibility?
- if two extension orders differ, what carries the difference?
- if they do not differ, what information was lost by the proposed boundary state?

Small computation is a microscope:
- find minimal inequivalent completions;
- compare partial objects with identical known statistics but different extendability;
- test conservation of an invented object.

Do not escalate timeouts.

If the representation needs larger and larger neighborhoods, mutate the representation instead.
